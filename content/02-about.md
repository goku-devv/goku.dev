## About

I've spent ten years building backends in Go, the last six at Autonomous, where I wrote the service framework our ~40 services boot on and much of the code that takes an order from checkout to the warehouse. Since 2021: **18,000+ commits across 61 repositories, main author of 33.**

What I optimise for: boring, observable systems. One transaction for the write, events for everything else, every hop traced, contracts before code. What I avoid: cleverness nobody can debug at 3 a.m. — hidden coupling, "temporary" synchronous calls between services, dashboards nobody reads.

Lately: tools that let AI agents work on real systems safely.
